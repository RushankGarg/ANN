# Artificial Neural Networks - Classification and Regression

This repository contains my implementations of Artificial Neural Networks (ANN) for solving both classification and regression problems as part of my Deep Learning learning journey.

## Projects

### 1. Date Fruit Classification
Implementation of an Artificial Neural Network for classifying different varieties of date fruits based on their features.

### 2. Power Plant Energy Prediction
Implementation of an Artificial Neural Network for predicting power plant output using a regression-based neural network.

- Backpropagation
- Classification
