# Artificial Neural Networks with PyTorch

This repository contains implementations of **Artificial Neural Networks (ANNs) using PyTorch** for both classification and regression problems. The projects demonstrate the complete deep learning workflow, including data preprocessing, feature scaling, neural network architecture design, model training, backpropagation, and evaluation.

## Projects

### 1. Date Fruit Classification

An Artificial Neural Network implementation for classifying different varieties of date fruits based on their numerical characteristics.

The project covers:

- Data preprocessing and exploration
- Feature selection and scaling
- ANN architecture using PyTorch
- Fully connected neural network layers
- Activation functions
- Loss calculation
- Optimizer configuration
- Forward propagation and backpropagation
- Model training across multiple epochs
- Classification performance evaluation

---

### 2. Power Plant Energy Prediction

An Artificial Neural Network regression model for predicting power plant output using numerical operational features.

The project covers:

- Data preprocessing
- Train-test splitting
- Feature scaling
- ANN regression architecture
- PyTorch `nn.Module`
- Fully connected layers
- Regression loss functions
- Gradient-based optimization
- Backpropagation
- Model training and evaluation
- Prediction on unseen data

## Installation

Clone the repository:

```bash
git clone https://github.com/RushankGarg/Artificial-Neural-Networks.git
cd Artificial-Neural-Networks
```

Install the required libraries:

```bash
pip install torch pandas numpy scikit-learn matplotlib jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Run either notebook to explore the corresponding ANN implementation.

## Learning Objectives

The main objective of this repository is to understand how Artificial Neural Networks work by implementing neural networks using PyTorch rather than relying only on high-level abstractions.

The implementations demonstrate how to:

1. Prepare data for neural networks
2. Convert data into tensors
3. Define neural network architectures
4. Perform forward propagation
5. Calculate model loss
6. Perform backpropagation
7. Update model parameters using optimizers
8. Train neural networks across multiple epochs
9. Evaluate models on unseen data
10. Apply ANNs to classification and regression problems
